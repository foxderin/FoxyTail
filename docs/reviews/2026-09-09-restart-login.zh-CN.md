# FoxyTail v1.2.1：重启登录提示与配置备份修复

本次处理两项实际故障：已登录设备重启时短暂出现登录卡，以及配置备份在 Android 上直接失败。保留 v1.2.0 的页面布局、子网路由接收、IPv6 和 Serve/Funnel 修复。

## 重启登录提示

根因是前端将 `NoState`、`NeedsMachineAuth` 和 `NeedsLogin` 归成了同一种状态。当前固定版本 Tailscale 启动先进入 `NoState`；此时控制客户端尚未确定连接状态，界面应显示加载中。`NeedsMachineAuth` 表示等待管理员审批，`NeedsLogin` 才表示需要用户执行认证。后端一直原样透传这些状态。

修复后，启动未定和等待审批显示连接恢复状态，不再提供误导性的登录操作；明确的 `NeedsLogin` 仍立即提供登录入口，包括主动登出和密钥失效。读取失败时隐藏陈旧登录卡，提交登录操作前再次确认状态。没有通过历史账号、已保存 Profile 或固定延时推断已登录，也没有增加轮询或自动认证请求。

固定版本 `ipn/ipnlocal/local.go` 的依据：

- 第 2672 行：启动置为 `NoState`。
- 第 2855 行附近：存在保存凭据时先恢复控制客户端登录，避免错误进入 `NeedsLogin`。
- 第 6176 行附近：`NoState` 应显示 Loading；认证失败、主动登出、密钥过期和机器审批分别判断。

## 备份失败

在已连接的 Android 16 设备上，`/system/bin/tar` 指向 `toybox 0.8.12-android`。原 API 在约 0.095 秒内返回失败。将原打包命令的输出目标替换为 `/dev/null` 后，直接得到 `tar: conf: No such file or directory`。

原命令依次使用 `-C /data/adb/foxytail conf` 和 `-C /data/adb/foxytail/scripts`。GNU/BSD tar 支持位置相关的目录切换，但 toybox tar 只保留一个工作目录，最后到 scripts 目录寻找 conf。原实现又吞掉了 tar 的错误详情。

新实现持有配置锁，将配置和可选钩子复制到私有暂存目录，再用一次 `-C` 生成归档。压缩文件先写入 `.partial`，通过归档读取校验、确认大小非零后才发布到手机 Download 目录。失败分别报告目录创建、复制、压缩、校验或发布的具体原因，并清理暂存、半成品和配置锁。

归档格式保持 `conf/` 与顶层两个可选钩子文件，与现有恢复入口兼容。备份范围为模块配置与钩子，不包含 Tailscale 登录凭据。测试中的恢复仅在隔离目录执行；真机没有执行恢复或修改认证信息。

前端改为会话任务：点击立即反馈进度，切页后继续执行，任务菜单可返回设置页查看结果。成功保留最近一次实际文件路径；失败持续显示原因并允许重试，不覆盖已有成功记录。缺失、空白或无效路径不会被当作成功。结果明确说明文件已保存到手机，并提供复制路径按钮。

后端在提交备份时不允许中途取消，因此该任务不显示取消按钮；普通可取消任务保持原行为。备份等待预算为 60 秒。

- 完整检查：94 项后端测试、524 对中英文文案、25 组 WebUI smoke；另有 TypeScript、ShellCheck、生产资源重建一致性和版本元数据检查。
- 备份测试使用真实 tar/gzip，由 Python 独立读取并逐字节核对，再调用实际恢复实现验证配置恢复和钩子停放。覆盖无钩子、有钩子、存储失败、归档损坏和清理。
- WebUI 回归覆盖备份按钮即时忙碌、防重复提交、跨页不中断、任务入口找回、复制路径、失败重试、保留旧成功结果、非法成功响应，以及备份不展示取消入口。
- 登录回归覆盖首次未登录、重启经过 `NoState`、跨页恢复、管理员审批、读取失败后的陈旧提示及真实认证需求。浏览器开发预览也检查了启动状态和备份结果布局；预览明确标注模拟数据，不随模块打包。
- 真机已生成 `/sdcard/Download/foxytail-backup-20260909-193014-27693.tar.gz`，大小 2608 字节，约 0.145 秒完成；归档包含 3 个配置和 2 个钩子，全部文件 SHA-256 与源文件一致。备份前后配置校验值一致，暂存目录已清理。
- 真机执行了一次服务重启：记录到 `Running → stopped → unreachable → NoState → Starting → Running`，约 15 秒恢复；两个采样点明确处于 `NoState`，全程未采到 `NeedsLogin`。配置保持不变。手机当时未显示 KernelSU 页面，因此此项为实际 API 状态轨迹验证；登录卡显隐由浏览器预览与 smoke 验证。

设备归档和详细验证记录保留在本地忽略目录 `dist/ui-preview/`，不进入 Git 或安装包。
