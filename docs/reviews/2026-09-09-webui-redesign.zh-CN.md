# FoxyTail WebUI v1.1.0 重构报告

本次重构覆盖全部 13 个页面，将界面从分散的表单和文字列表整理为统一的网络管理界面。根据反馈，服务开关、运行模式与重启入口放入固定顶栏；图标统一使用项目已有的 Material Symbols 官方 SVG，不保留自绘品牌或系统图标。

## 页面与交互

| 页面 | 主要变化 |
| --- | --- |
| 全局导航 | 手机使用实心选中图标的底栏，桌面使用分组侧栏；所有页面顶部均可操作服务与模式。 |
| 仪表盘 | 连接健康主卡、在线设备／运行时长指标、本机地址复制、出口概览和快捷入口；删除重复的模式与运行状态指示。 |
| 节点 | 系统类型图标、名称／IP／系统搜索、在线筛选、详情弹窗、可键盘操作的拓扑。 |
| 出口 | 明确区分当前出口、所选出口、待确认状态；选择后显式应用；离线节点不可应用；测速结果保留。 |
| 流量 | 自适应 SVG 图表、触摸和键盘读取、可展开数据表、下载／上传指标、节点排行和应用发送量。 |
| 更多 | 按网络工具、设备与账户、维护与偏好分组，带图标与入口指示。 |
| 隧道 | 连接路径和模式指示卡、本机 DNS 与原生 DNS 状态分开、手动 DNS 检查、SOCKS5 与中继测试。 |
| 路由 | 应用范围策略卡、独立目标网段、未保存提示、应用搜索和分页；保留原生 TUN 范围限制。 |
| 设置 | 外观、网络、后台、高级、备份、恢复分组；持续显示待应用状态；高级规则和钩子按需读取。 |
| 账户 | 主登录流程、当前账户、切换状态；认证密钥和 Headscale 放在高级登录方式中。 |
| Serve / Funnel | 清晰区分私网与公网映射，保留真实协议、端口和处理路径，增加输入校验及操作反馈。 |
| 文件 | 收件箱数量和大小、文件过滤、路径复制、发送设备选择和全局传输任务。 |
| 日志 | 搜索、行号、读取数量、大小写、换行、复制与暂停刷新；筛选只作用于已加载行。 |
| 诊断 | 收集前说明、运行进度、可取消任务、完成结果和路径复制。 |

## 视觉与组件

- 浅色采用中性背景和白色卡片，深色采用石墨表面，狐狸橙作为强调色；默认跟随系统。
- 统一页面标题、图标容器、指标卡、状态标签、表单、按钮、对话框和消息反馈；去掉泛泛的页面说明和重复提示。
- 首次加载显示结构化骨架；刷新保留已有内容；失败显示原因和重试；空数据给出用途说明。
- 控件触控区至少 44px，选中态同时用形状、文字或状态语义表达。
- 页面进入、点击反馈和骨架采用轻量 CSS 动画；遵循 `prefers-reduced-motion`。
- 对话框默认聚焦取消，关闭后恢复焦点；页签支持方向键，图表提供数据表。
- 底栏实际高度用于内容及消息避让，同时兼容 KernelSU 窗口 inset 和浏览器安全区。
- 搜索框仅保留一份可见提示；首页不重复显示更新频率、设备名或运行模式。测速放在顶部操作区，结果和进行中任务按需展示。

参考工作直接读取了 HybridMount 的 `MiuixLayout.vue`、`StatusCard.vue`、状态页、配置页、主题与导航实现。采用其状态分层、分组信息行和操作反馈思路，FoxyTail 继续使用 Solid 与原生控件实现。未引入该项目的整套运行时组件或保留隐藏页面的轮询方式。

## 代码组织

- `navigation.ts`：统一导航分组、主页面与次级页面归属。
- `AppShell`：导航、页面标题、全局任务入口与顶部操作区。
- `ServiceControls`：服务及模式操作生命周期独立于当前页面，切页不会丢失正在执行的操作。
- `components/Basics.tsx`、`components/ui.tsx`：共享显示组件、原生控件、加载和反馈。
- `pages/network.css`、`pages/tools.css`：领域页面布局；通用 token 和基础控件仍由 `style.css` 管理。
- `i18n-*.ts`：按领域拆分词典，中心统一组合；AST 检查器验证导入、展开、重复、空值和双语对应。
- `pages/tools-refresh.ts`：合并重复刷新，保留写入之后所需的重新读取，丢弃已经过期的响应。
- `dev/preview.ts`：带明确标记的开发预览，提供正常、慢响应、空数据、失败、未登录和无 root 场景。生产包不包含模拟桥、模拟数据及 smoke 测试入口。

## 一并修复的行为问题

1. **出口确认竞态**：写入后可能碰到旧状态读取。新增 `refreshStatus({ afterCurrent: true })`，合并一次后续读取，只有新快照确认目标后才显示成功。
2. **未知状态误报**：读取失败时不再把未知出口显示成本机网络，也不继续用绿色状态宣称数据新鲜。
3. **假零流量**：小时统计现在只计算有效接口采样；没有采集与真实零流量分别显示为空状态和零值图表。
4. **写后刷新丢失**：服务映射、收件箱和账户读取采用刷新队列，避免旧响应覆盖刚完成的操作。
5. **开关回滚**：后端拒绝配置时，显式恢复原生 checkbox 的状态，避免界面与实际配置不一致。
6. **恢复反馈丢失**：恢复后持续展示原配置备份位置及钩子停放信息，支持复制。
7. **复制与焦点**：成功或失败均清理临时文本框并恢复焦点；重新连接期间不再错误显示“需要登录”。
8. **服务开关超时**：真机发现旧 DNS 进程扫描在读取已退出进程的 `/proc/<pid>/cmdline` 时持续循环，导致服务控制锁长期被占用。改为先验证可执行文件、再读取最多 4096 字节且限时 2 秒的参数快照，并修复所有同类扫描入口。
9. **服务实际状态**：进程存活与 LocalAPI 可用性分别判断。命令失败后重新读取实际状态；未知状态使用禁用的居中开关与明确反馈，不再保留有误导性的开启／关闭外观。超时后仍可手动核验；异常但存活的服务可停止或重启。运行中的快照本身不能证明重启成功。
10. **IPv6 能力检测与回退**：DNS 启动先检查原生 IPv6 NAT；不可用时查找系统现有 `ip6table_nat` 模块，交由标准模块加载器处理依赖和内核校验，加载总预算为 6 秒，随后再次验证实际能力。模块缺失或失败时保留 IPv6 隧道、`::1` 监听和双栈解析，继续使用 IPv4 DNS 透明转发。隧道页手动检查后显示原生／内核模块／兼容路径及回退原因；状态读取不会加载模块。
11. **完整域名 AAAA 缺失**：当前原生 Tailnet DNS 对完整域名返回空 AAAA，短名查询和 IPv6 数据面正常。基于 Tailscale 官方状态中的双栈地址，同时生成完整域名与短名映射，沿用账号／名称／地址变化的同步机制。
12. **路由状态反复误报**：Android 旧版 iproute2 在按协议和接口筛选后会省略这两个字段。比较时规范这些字段，仍以内核过滤结果判断归属，保留外来路由和 IPv6 路由。规则写入增加最多 2 秒的 xtables 锁等待，读取仍立即返回。

## 性能约束与验证

保留 v1.0.5 的异步 `spawn`、首帧后调用桥、销毁页面时取消未启动读取、按请求 ID 取消与替换等待机制。未增加后台自动 DNS 检查、外部字体或大型组件运行时。流量为缺失值时不枚举应用名称，日志筛选不发起 root 调用。

验证覆盖 77 项后端测试、ShellCheck、类型检查、491 项双语与主题检查、21 组 WebUI smoke、生产文件重建一致性和发布元数据一致性；新增回归覆盖搜索无 root 调用、出口显式应用、写后刷新竞态、开关失败回滚、恢复结果、缺失／零流量、固定顶栏控件跨页操作，以及内核模块精确匹配、加载结果核验、失败回退和总时间预算。

浏览器已检查手机尺寸、桌面英文、深浅主题、慢响应骨架和失败重试。已在 Android 16 / KernelSU 3.3.0 设备部署候选版检查实际界面；安装前保留原 WebUI 与统计脚本备份。真实设备截图保存在本地构建目录，不随公开源码或模块包发布。

最终设备抽测：5 个主页面连续切换 11 次，全部匹配目标页面，ADB 触发到观测到页面标题的时间为 28–76ms（包含 ADB 与观测开销，不等同于 INP）。本次新 WebView 启动的 first-contentful-paint 为 200ms，属于单次设备样本，不作为跨设备性能保证。页面宽度与滚动宽度均为 427 CSS px，无横向溢出。临时 WebView 调试开关与端口转发已恢复清理。

服务修复后的实际后端关闭约 2.1 秒、启动约 2.7 秒，控制结果与真实守护进程状态一致。这是 ADB 调用完整控制链路的观测耗时；本轮 UI 点击测试因页面离开前台而停止，不据此报告点击延迟。该设备内核未启用 IPv6 NAT，现有系统模块目录也没有对应模块，自动选择兼容路径；IPv6 配置保持开启。

最终 IPv6 复测：经 `::1` 查询短名 AAAA、完整域名 UDP／TCP AAAA，均返回与 Tailscale 官方状态一致的节点 IPv6 地址；IPv6 路由经过 `tailscale0`，节点 ping 为 2/2 成功，Android 系统按完整域名执行 IPv6 ping 为 1/1 成功。检测接口返回 `running / fallback / missing`，对应 DNS 正常、兼容路径、缺少 NAT 模块；兼容路径不提供 IPv6 DNS 透明拦截。
